# Project Summary

## Project Name

MoonEcoGuard

## Short Description

MoonEcoGuard is a pure MoonBit biodiversity data governance toolkit for Darwin Core-style field survey records. It imports CSV/TSV occurrence data, validates ecological and geographic quality rules, summarizes dataset health, exports JSON/GeoJSON/Markdown, and protects sensitive species coordinates before public release.

## Chinese Description

MoonEcoGuard 是一个面向自然保护区、植物园、博物馆和科研调查队的生物多样性数据标准化与质量检测工具。项目聚焦 Darwin Core / Darwin Core Archive 风格的野外调查记录，提供 CSV/TSV 导入、字段标准化、生态数据校验、GIS 空间检查、统计报告、格式转换，以及对濒危或高风险物种坐标的自动模糊化保护。

## Core Value

- Standardizes inconsistent field-survey spreadsheets into Darwin Core-inspired records.
- Detects missing identifiers, invalid coordinates, non-ISO dates, duplicate observations and suspicious spatial data.
- Flags sensitive taxa that still expose exact coordinates.
- Produces public-safe exports for downstream mapping, GBIF/IPT preparation and manual data review.
- Documents that automated coordinate protection reduces disclosure risk but does not replace expert review or formal data-release governance.
